**Описание проекта**  

Telegram-бот для управления задачами и списком дел. Позволяет создавать, редактировать и удалять задачи, а также получать случайные задания для саморазвития.  

**Основные возможности**
Управление задачами:добавление, просмотр, редактирование и удаление  

Случайные задания: получение мотивирующих задач на день  

Организация по датам: возможность привязывать задачи к конкретным датам  

Просмотр списка: вывод всех задач или задач по дате
